TOPIC: Confusion Matrix
A confusion matrix is a table showing model prediction results against actual labels. For binary classification: True Positive (correctly predicted positive), True Negative (correctly predicted negative), False Positive (predicted positive, actually negative), False Negative (predicted negative, actually positive). From these four values, all other classification metrics are derived.

TOPIC: Accuracy, Precision, Recall, F1
Accuracy = (TP + TN) / Total. Poor metric for imbalanced datasets. Precision = TP / (TP + FP) — of all predicted positives, how many were correct. Recall = TP / (TP + FN) — of all actual positives, how many did we catch. F1 Score = 2 × (Precision × Recall) / (Precision + Recall) — harmonic mean, balances both. Use F1 for imbalanced classes.

TOPIC: ROC-AUC
ROC (Receiver Operating Characteristic) curve plots True Positive Rate vs False Positive Rate at different thresholds. AUC (Area Under Curve) summarizes the curve as a single number between 0 and 1. AUC of 0.5 means random guessing. AUC of 1.0 means perfect classification. Useful for comparing models regardless of threshold. Works for binary classification.

TOPIC: Mean Squared Error and RMSE
MSE (Mean Squared Error) averages the squared differences between predicted and actual values. Penalizes large errors more. RMSE (Root Mean Squared Error) is the square root of MSE — in same units as the target variable, easier to interpret. MAE (Mean Absolute Error) averages absolute differences — more robust to outliers than MSE.

TOPIC: Hyperparameter Tuning
Hyperparameters are settings set before training (learning rate, tree depth, number of layers). Grid Search tries all combinations of specified values. Random Search samples random combinations — more efficient. Bayesian Optimization uses past results to choose next values intelligently. Always tune on validation set, never on test set.

TOPIC: Learning Curves
Learning curves plot model performance vs training set size or training epochs. High training error + high validation error = underfitting (need more complexity). Low training error + high validation error = overfitting (need more data or regularization). Converging training and validation error = good fit. Plotting learning curves is standard practice for diagnosing model behavior.
